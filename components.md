Components Required

This file lists the components planned for the Solar Energy Monitoring System.

No.| Component| Purpose
1| Solar panel| Converts sunlight into electrical energy
2| INA219 sensor| Measures voltage and current
3| Arduino Uno| Reads sensor data and processes it
4| Connecting wires| Connects the components
5| Breadboard| Helps build the circuit
6| USB cable| Connects the Arduino to a computer for programming

Optional Components

- OLED display — displays voltage and current readings.
- LED or buzzer — provides a visual or audible alert.

Notes

The final component list will be updated after checking the actual circuit and available hardware.
